A small dependency-free Node program that writes one short, original text designed to leave the AI judge curious — a quiet scene, one unexplained detail, and a question left hanging. Built for the $50 make.fun bounty "Make the AI judge feel curious".

## Run it

```sh
node main.ts
```

This writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is not set). Running it twice produces byte-identical output.
